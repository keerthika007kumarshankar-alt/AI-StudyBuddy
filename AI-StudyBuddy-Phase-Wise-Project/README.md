# AI StudyBuddy – Phase-Wise Project

This repository reorganizes the submitted **AI StudyBuddy Backend** project according to the 8-phase structure used in the referenced AI/ML/Gen-AI project template.

## Phases
1. Brainstorming & Ideation
2. Requirement Analysis
3. Project Design Phase
4. Project Planning Phase
5. Project Development Phase
6. Project Testing
7. Project Documentation
8. Project Demonstration

## Project
AI StudyBuddy is an AI-powered learning backend using Node.js, Express.js, MongoDB, JWT/RBAC and Google Gemini.

## Source Code
The original submitted backend is preserved under `Project Source Code/`.

## Important
Before running the backend, create a `.env` file inside `Project Source Code/` and provide the MongoDB URI, JWT secrets and Gemini API key.

See Phase 5 for setup and Phase 8 for the demonstration flow.
